1. **LayeredRenderPipeline**: Formalize the 4-stage pipeline
   - Stage 1: Frustum Culling (from Plan 05-01)
   - Stage 2: Depth Sorting
   - Stage 3: Occlusion Detection
   - Stage 4: Rendering

2. **LODManager**: Distance-based detail reduction
   - Near (<200px): Full detail (shadows, animation)
   - Medium (200-500px): Simplified (no shadows, static)
   - Far (>500px): Placeholder only

3. **GameViewport integration**: Replace ad-hoc rendering with pipeline

- Pipeline should be configurable (enable/disable stages for debugging)
- Each stage receives input from previous, outputs to next
- LOD thresholds configurable per-entity type
- Distance calculation: Euclidean from camera center to entity center

    ```typescript
    private renderEntitiesUnified(snapshot: RuntimeSessionState): void {
      const renderStart = performance.now();
      
      // Collect all entities into a unified list
      const allEntities = this.collectEntities(snapshot);
      
      // Build render context
      const camera = this.scene.cameras.main;
      const context: RenderContext = {
        camera: {
          x: camera.worldView.x,
          y: camera.worldView.y,
          width: camera.worldView.width,
          height: camera.worldView.height,
          zoom: camera.zoom
        },
        playerPosition: {
          x: snapshot.player.x * tileSize,
          y: snapshot.player.y * tileSize
        },
        frameCount: this.frameCount
      };
      
      // Process through pipeline
      const result = this.renderPipeline.process(allEntities, context);
      
      // Apply LOD to final entities
      const cameraCenterX = context.camera.x + context.camera.width / 2;
      const cameraCenterY = context.camera.y + context.camera.height / 2;
      
      for (const entity of result.finalEntities) {
        const lod = this.lodManager.getLODForEntity(
          entity.x, entity.y, cameraCenterX, cameraCenterY, entity.id
        );
        this.renderEntityWithLOD(entity, lod);
      }
      
      // Hide entities not in final set
      this.hideNonVisibleEntities(result.finalEntities);
      
      // Record timing
      const renderTime = performance.now() - renderStart;
      this.performanceMonitor?.recordRenderTime(renderTime);
      
      // Log pipeline stats periodically (every 60 frames)
      if (this.frameCount % 60 === 0) {
        console.log('[RenderPipeline]', {
          totalTime: result.totalTimeMs.toFixed(2) + 'ms',
          stages: Object.fromEntries(result.stageTimings),
          entities: Object.fromEntries(result.entitiesAtEachStage)
        });
      }
    }
    ```
