## Current State
The engine-core package has no coordinate type safety - positions use raw `number` for x/y throughout. GameViewport.ts uses hardcoded conversions like `tile.x * RuntimeAssetLibrary.tileSize + RuntimeAssetLibrary.tileSize * 0.5` inline.

## Architecture Context
Per ARCHITECTURE.md, this is a Stardew-like pseudo-3D system (not true 3D). Four layers: Phaser primitives → engine scene graph → content metadata → visual packs. Coordinate types are the foundation that subsequent phases (depth sorting, spatial indexing) depend on.

## Conventions
- PascalCase for type definitions: TileCoord, WorldCoord
- Use branded types for compile-time distinctness: type WorldCoord = number & { __brand: 'world' }
- 500 line file limit - keep coordinate module focused

5. **Factory functions** that enforce brand creation:
   ```typescript
   export function tileX(value: number): TileX { return value as TileX; }
   export function tileY(value: number): TileY { return value as TileY; }
   export function worldX(value: number): WorldX { return value as WorldX; }
   export function worldY(value: number): WorldY { return value as WorldY; }
   ```

<task type="auto">
  <name>Task 2: Create coordinate conversion utilities</name>
  <files>packages/engine-core/src/coordinates.ts</files>
  <action>
Add CoordinateConverters namespace to packages/engine-core/src/coordinates.ts with conversion functions:

1. **tileToWorld**: Convert TileCoord to WorldCoord (center of tile)
   ```typescript
   export interface TileSize { readonly value: number; }
   export function createTileSize(value: number): TileSize { return { value }; }
   
   export const CoordinateConverters = {
     tileToWorld(
       tile: TileCoord, 
       tileSize: TileSize,
       options?: { center?: boolean }
     ): WorldCoord {
       const offset = options?.center !== false ? tileSize.value * 0.5 : 0;
       return worldCoord(
         tile.x * tileSize.value + offset,
         tile.y * tileSize.value + offset
       );
     },
     
     worldToTile(
       world: WorldCoord, 
       tileSize: TileSize
     ): TileCoord {
       return tileCoord(
         Math.floor(world.x / tileSize.value),
         Math.floor(world.y / tileSize.value)
       );
     },
     
     worldToDepth(
       world: WorldCoord,
       heightOffset: number,
       worldBounds: { minY: number; maxY: number }
     ): DepthValue {
       // Depth = y + heightOffset, normalized to 0-1
       const rawDepth = world.y + heightOffset;
       const normalized = (rawDepth - worldBounds.minY) / (worldBounds.maxY - worldBounds.minY);
       return depthValue(Math.max(0, Math.min(1, normalized)));
     },
     
     applyAnchorOffset(
       world: WorldCoord,
       spriteHeight: number,
       anchor: AnchorPoint
     ): WorldCoord {
       // Adjust world position based on anchor point
       // Bottom-center (0.5, 1.0): no offset needed - origin at bottom
       // Center (0.5, 0.5): offset up by half height
       const offsetY = (anchor.y - 1.0) * spriteHeight;
       return worldCoord(world.x, world.y + offsetY);
     }
   };
   ```

2. **Constants for standard tile sizes**:
   ```typescript
   export const DEFAULT_TILE_SIZE: TileSize = createTileSize(16);
   export const PHASER_DEFAULT_TILE_SIZE: TileSize = createTileSize(16);
   ```

Key design: Type signatures enforce correct usage. Cannot accidentally pass raw numbers where branded types expected.
