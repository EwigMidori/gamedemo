# Requirements: Gamedemo 伪3D视觉改进 v1.2

**Version:** v1.2 (Scalability Fix)  
**Shipped:** 2026-04-01  
**Problem:** 距离出生点越远，游戏越卡顿  
**Core Value:** 流畅的游戏体验不应该随探索距离而衰减

## Summary

Fixed critical performance bug where FPS degraded as player moved away from spawn. Root cause was O(n) traversal of ever-growing resource/structure arrays.

**Solution:** Implemented frustum culling for all renderers + distant entity cleanup systems.

**Files Changed:** 5 files, +328 lines, -152 lines

---

## Phase 6: Scalability & Distance Culling

### PERF-09: Resource Frustum Culling ✅

**Requirement:** 对 `snapshot.resources` 应用视锥剔除，只处理视野内的资源

**Implementation:**
- Modified `renderResources()` with early-out frustum culling
- Only processes resources within 40×40 tile view radius
- Code: `gameViewport.ts:890`

### PERF-10: Structure Frustum Culling ✅

**Requirement:** 对 `snapshot.placedStructures` 应用视锥剔除

**Implementation:**
- Applied to `renderStructures()`, `renderPlantedResources()`, `renderDrops()`
- Created `calculateFrustumBounds()` helper (calculated once per frame)
- Code: `gameViewport.ts:1010`

### PERF-11: Distant Entity Cleanup ✅

**Requirement:** 清理远离玩家、不再可见的实体

**Implementation:**
- Created `DistantEntityCleanupSystem` in `mods/core-worldgen/`
- Runs every 300 frames (~5 seconds)
- Removes depleted resources >100 tiles from player
- Keeps active resources and all structures
- Code: `distantEntityCleanupSystem.ts` (49 lines)

### PERF-12: World Tiles Optimization ✅

**Requirement:** 优化 `world.tiles` 遍历

**Implementation:**
- Rewrote `renderTerrain()` to use view-based rendering (40 tiles radius)
- Added `cleanupDistantTerrainSprites()` — destroys sprites >50 tiles away
- Automatically re-creates sprites when returning to cleaned areas
- Code: `gameViewport.ts:880`
